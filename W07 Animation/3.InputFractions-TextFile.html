Đề bài & ví dụ

Yêu cầu

  • Nhập từ bàn phím hai phân số: mỗi phân số có tử số num và mẫu số denom.
  • Ghi ra file D:\2fractions-output.txt, mỗi phân số một dòng, dạng tử mẫu.
  • Nếu không tạo được file thì in Can not create file.
Kiểu Fraction là một struct gom hai số nguyên num và denom thành một biến.

BƯỚC 2

Phân tích: chia bài toán thành các hàm

HàmTham sốNhiệm vụ
mainargc, argv (không dùng)Khai báo a, b, f; gọi nhập; mở file; gọi ghi; đóng file
inputFractionFraction &pNhập tử và mẫu từ bàn phím vào p
saveFractionofstream &f, Fraction pGhi “tử mẫu” rồi xuống dòng vào file

Fraction &p

Tham chiếu: hàm sửa được biến gốc. Cần thiết khi nhập, vì kết quả phải về a, b của main.

Fraction p

Giá trị: hàm nhận một bản sao. Đủ dùng khi chỉ cần đọc, như ghi ra file.

ofstream &f

Luồng file không sao chép được, nên bắt buộc truyền tham chiếu.

Mở file thành công

Nhánh else chạy: ghi a, ghi b, đóng file. Màn hình không in thêm gì.

Không tạo được file

is_open() là false: nhánh if in Can not create file, không ghi và không cần đóng.

File này gồm 4 số cách nhau bởi dấu cách và xuống dòng, nên chương trình đọc file bằng >> có thể đọc lại đúng 3, 4, 5, 6.
TỔNG KẾT

Lưu ý & tóm tắt

Mẫu số bằng 0

Chương trình không kiểm tra denom = 0. Cần kiểm tra khi nhập hoặc tính toán.

Không kiểm tra cin

Nhập chữ thay vì số làm cin lỗi, các lệnh đọc sau đó đều thất bại. Dùng cin.fail().

Ghi đè file cũ

open() xóa nội dung cũ nếu file đã tồn tại. Muốn nối thêm, mở với ios::app.

Đường dẫn D:

Chỉ có trên Windows có ổ D. Ở nơi khác is_open() trả về false.

Nhập

Fraction &p: tham chiếu để ghi về biến gốc.

Mở file

f.open() rồi kiểm tra is_open().

Ghi file

Ghi “tử mẫu” và endl, một phân số một dòng.

Đóng file

Gọi f.close() để dữ liệu xuống đĩa.

Common mistakes newbies make

1. Missing & on n

With int n in loadFractionArray, the count is set on a copy. main keeps n = 0 and prints nothing. Fix: int &n.

2. Off-by-one loop bound

i <= n loads one extra element, so a[n] holds garbage. Keep i < n.

3. Printing the array size

printFractionArray(a, 100) prints all 100 slots, most of them unset. Pass the count n, not the array size.

4. Forgetting [i]

loadFraction(f, a) does not match the function, which expects one Fraction. Use a[i].

5. Count and data disagree

If the file says 3 but only lists 2 fractions, the last reads fail silently and a[2] keeps garbage. Check the file matches its count.

6. More than 100 fractions

If the file says 150, the loop writes past a[99], which breaks the program in ways that are hard to trace. Make the array big enough, or check n against 100 first.

Tip: print n right after loading. If it is not what you expect, the problem is in the read.

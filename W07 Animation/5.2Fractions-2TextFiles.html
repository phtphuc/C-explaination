Next: the mistakes newbies make most often.

Common mistakes newbies make

1. Missing & in inputFraction

Writing Fraction p changes a copy. a stays unset and the input is lost. Fix: Fraction &p.

2. Passing ofstream by value

saveFraction(ofstream f, ...) does not compile, because streams cannot be copied. Fix: ofstream &f.

3. Single backslash in the path

"D:\fraction1-output.txt" contains \f, an escape code for form feed, so the name breaks. Fix: "D:\\fraction1-output.txt" or "D:/fraction1-output.txt".

4. Wrong check with &&

!f1.is_open() && !f2.is_open() only fails when both files fail. Use || so either failure is caught.

5. Forgetting the space or endl

f << p.num << p.denom writes 34, and later reads see one number. Keep the " " between values.

6. Swapping the files

Writing saveFraction(f1, b) puts 5/6 in the file meant for a. Match f1 with a and f2 with b.

Tip: if an output file is empty or missing, check the path first, then the is_open() result.

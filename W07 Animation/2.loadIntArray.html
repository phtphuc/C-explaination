Đề bài & file input

Yêu cầu

  • Đọc từ file D:\intarray-input.txt: số đầu tiên là n, sau đó là n số nguyên.
  • In n phần tử ra màn hình, cách nhau bởi dấu cách.
  • Nếu file không mở được thì in File does not exist. Nếu n = 0 thì in Empty array.
Đọc file bằng >> bỏ qua dấu cách và xuống dòng, nên không cần quan tâm bố cục file.

TỔNG KẾT

Lưu ý & tóm tắt

Mảng cố định

Không kiểm tra n. Nếu n > 100, vòng lặp ghi ra ngoài mảng.

File thiếu số

Nếu file có ít số hơn n, f >> thất bại và a[i] không hợp lệ.

Không kiểm tra >>

Nên kiểm tra f.fail() sau khi đọc để phát hiện lỗi định dạng.

Đường dẫn D:

Chỉ có trên Windows có ổ D. Ở nơi khác is_open() trả về false.

Mở

Mở file bằng f.open(), rồi kiểm tra is_open().

Đọc

Đọc n, rồi đọc n phần tử bằng f >>.

In

In các phần tử, hoặc “Empty array” khi n = 0.

Đóng

Gọi f.close() khi xong việc.
